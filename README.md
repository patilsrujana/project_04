# project_04

Project Description :
  My Productivity App is a simple web application developed using React.js, JavaScript, and CSS. 
  It helps users manage their daily tasks and write important notes in one place.
  The application provides a simple and user-friendly interface for adding and deleting tasks and notes.

Objectives :
  1.To manage daily tasks easily.
  2.To add and delete tasks.
  3.To write and delete personal notes.
  4.To understand React components and state management.
  5.To create a responsive web application using CSS.

Features :
    Add Tasks: Add new tasks to the to-do list.
    Delete Tasks: Remove tasks when they are no longer needed.
    Add Notes: Write and save notes while using the application.
    Delete Notes: Remove unwanted notes.
    Responsive Design: Use the application on desktop and mobile screens.
    Simple Interface: Easy-to-use design for beginners.

Technologies Used :
    React.js
    JavaScript
    HTML5
    CSS3
    Vite
    
Installation and Setup
    Download or clone this repository.
    Open the project folder in Visual Studio Code.
    Open the terminal.
    Install the required dependencies:
    npm install
    Start the development server:
    npm run dev
    Open the local URL displayed in the terminal, usually http://localhost:5173

How to Use :
    Open the application in your browser.
    Enter a task in the task input field.
    Click Add Task to add the task.
    Click Delete to remove a task.
    Enter text in the notes section.
    Click Add Note to add a note.
    Click Delete to remove a note.

Learning Outcomes :
    Understanding React functional components.
    Using the useState Hook.
    Handling user input with event handlers.
    Displaying lists using the map() method.
    Removing items using the filter() method.
    Styling web pages using CSS.
    Running a React application using Vite.


    The My Productivity App project demonstrates the basic concepts of React development. 
    It provides a simple way to manage tasks and notes while helping beginners understand frontend web development.
